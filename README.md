# AI skills

A collection of skills I've built for various AI tasks

## Skills

- [Review Work](./review-work/SKILL.md) - a skill to get your coding agent to review its work.
- [Write Blog Post](./write-blog-post/SKILL.md) - write a blog post in Jim Bennett's voice.
- [Write Conference Talk](./write-conference-talk/SKILL.md) - write a conference talk in Jim Bennett's style. Ships with a 14-talk transcript corpus + 12 source-deck extractions and a consolidated style analysis (`ANALYSIS.md`) as reference material.
- [Keynote Decks](./keynote-decks/SKILL.md) - build, modify, and audit Apple Keynote decks via AppleScript. Captures Jim's visual-style defaults (Basic Black theme, 1920×1080, fork-an-existing-deck pattern) and reusable AppleScript helpers for extract / export-PNG / inspect-theme, plus a Python generator template.
- [Save Research](./save-research/SKILL.md) - persist research artifacts to `~/.research/` so sources, quotes, and synthesis survive across sessions, crashes, context compaction, and worktree switches.
- [Evaluate the Week](./evaluate-the-week/SKILL.md) - produce a script outline for a short weekly "week in AI + latest from Arize" video, styled after Christina Warren's *The Download*. Ships a stdlib-only gather script that pulls the past week from free AI-news, framework, Arize, and fun/viral sources.
